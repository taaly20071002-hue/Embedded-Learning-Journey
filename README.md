## 目录结构

每个实验一个独立工程目录,包含:

```
XX-实验名/
├── main.c            # 主程序
├── *.c / *.h         # 各模块驱动
├── project.uvproj    # Keil 工程文件
└── (Objects/ 等编译产物已被 .gitignore 排除)
```

## 约定

- 每完成一个实验 → commit + push
- commit message 格式:`feat(实验名): 完成XX功能`
- 编译产物不提交(见 .gitignore)
