# 引脚对照表(普中 51 开发板 / STC89C52RC)

> ⚠️ **本文档的引脚是实测确认的,不是从教程抄的。**
> 不同开发板引脚可能完全不同,请以你自己的板子为准。

## 如何验证自己的引脚(端口探测法)

不确定某个外设接在哪个脚?用这个方法**实测**:

```c
/* 读整个 P3 端口,显示到数码管/LCD */
unsigned char p3val = P3;
```

然后观察:
- 不操作时:`P3 = 0xFF = 255`
- 按下某个按键:某一位变 0,数字变小

**反推表(读到的值 → 哪个位为 0 → 哪个引脚):**

| 显示值 | 十六进制 | 二进制 | 为 0 的位 | 引脚 |
|---|---|---|---|---|
| 255 | `FF` | 1111 1111 | 无 | 没按 |
| 254 | `FE` | 1111 1110 | bit0 | P3.0 |
| 253 | `FD` | 1111 1101 | bit1 | P3.1 |
| 251 | `FB` | 1111 1011 | bit2 | P3.2 |
| 247 | `F7` | 1111 0111 | bit3 | P3.3 |
| 239 | `EF` | 1110 1111 | bit4 | P3.4 |
| 223 | `DF` | 1101 1111 | bit5 | P3.5 |
| 191 | `BF` | 1011 1111 | bit6 | P3.6 |
| 127 | `7F` | 0111 1111 | bit7 | P3.7 |

## 完整引脚表

### GPIO 与按键

| 外设 | 引脚 | 电平约定 | 说明 |
|---|---|---|---|
| LED D1~D8 | `P2.0` ~ `P2.7` | **低电平点亮** | 灌电流驱动 |
| 独立按键 K1 | `P3.1` | 低电平 = 按下 | 与串口 RXD 复用 |
| 独立按键 K2 | `P3.0` | 低电平 = 按下 | 与串口 TXD 复用 |
| 独立按键 K3 | `P3.2` | 低电平 = 按下 | |
| 独立按键 K4 | `P3.3` | 低电平 = 按下 | |
| 矩阵键盘 | `P1.0` ~ `P1.7` | 低电平 = 按下 | 行 P1.4~P1.7,列 P1.0~P1.3 |

### 显示

| 外设 | 引脚 | 说明 |
|---|---|---|
| 数码管段码 | `P0` | 共阴极段码(a~g,dp) |
| 数码管位选 | `P2.2` / `P2.3` / `P2.4` | 经 74HC138 译码,选 8 位数码管 |
| LCD1602 RS | `P2.6` | 寄存器选择(0=指令,1=数据) |
| LCD1602 RW | **`P3.7`** | **读写选择(0=写,1=读)** |
| LCD1602 EN | `P2.7` | 使能(下降沿执行) |
| LCD1602 D0~D7 | `P0` | 8 位数据总线 |
| LED 点阵 SER | `P3.4` | 74HC595 串行数据 |
| LED 点阵 SCK | `P3.6` | 74HC595 移位时钟 |
| LED 点阵 RCK | `P3.5` | 74HC595 锁存时钟 |

### 通信

| 外设 | 引脚 | 说明 |
|---|---|---|
| UART RXD | `P3.0` | 接收(与 K2 复用) |
| UART TXD | `P3.1` | 发送(与 K1 复用) |
| I2C SCL | `P2.1` | AT24C02 时钟线 |
| I2C SDA | `P2.0` | AT24C02 数据线 |
| DS1302 SCLK | `P3.6` | 三线 SPI 时钟 |
| DS1302 IO | `P3.4` | 三线 SPI 数据 |
| DS1302 CE | `P3.5` | 三线 SPI 片选 |
| DS18B20 DQ | `P3.7` | 单总线数据 |

| 外设 | 引脚 | 说明 |
|---|---|---|
| 蜂鸣器 | `P1.5` | 无源蜂鸣器,需方波驱动 |

## ⚠️ 引脚复用与冲突

### 1. 按键与串口复用

```
K1 = P3.1 = TXD
K2 = P3.0 = RXD
```

**含义**:用串口通信时(K1/K2 会被串口占用),按 K1/K2 会干扰串口数据;
反之串口通信时 K1/K2 检测也会受影响。

**解决**:用串口的实验里,按键改用 K3/K4;或者分时使用。

### 2. 74HC595 与 DS1302 引脚重叠

```
74HC595: SER=P3.4  SCK=P3.6  RCK=P3.5
DS1302 : IO=P3.4   SCLK=P3.6 CE=P3.5
```

**含义**:点阵屏和 DS1302 共用同一组引脚!**不能同时使用**(除非分时复用并正确处理片选)。

### 3. P0 口需要上拉

```
8051 的 P0 口是"开漏输出",没有内部上拉
→ 作为输入时要先写 1(P0 = 0xFF)
→ 作为输出驱动 LED 时要加上拉电阻(开发板已加)
```
